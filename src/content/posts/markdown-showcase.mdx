Good writing deserves a comfortable place to live. This sample gathers the elements you can use in an article or a video transcript, so you can see how they look together in **light and dark mode**.

Treat this page as a working specimen: follow the section links in the table of contents, copy a code block, or open the image. For the settings behind the page, read the [theme configuration guide](/posts/theme-configuration/).

## Text and links

A normal paragraph sets the rhythm. Use **bold text** to emphasize an idea, _italics_ for a gentle change in tone, and ~~strikethrough~~ for a visible correction. An inline command such as `pnpm dev` stays close to the sentence it belongs to.

Links can point to [another article](/posts/build-small-stay-curious/), a [section on this page](#tables), or an [external reference](https://astro-paper.pages.dev/posts/astro-paper-v6/). This is an original demonstration for the creator theme, inspired by the structure of AstroPaper’s release notes.

You can also add a footnote without interrupting the paragraph.[^specimen] A forced line break is useful for a short verse:

Start with a question.  
Make something small.  
Leave room for curiosity.

## Lists and tasks

An unordered list works well for a few related ideas:

- Protect a small block of focused time.
- Keep a notebook within reach.
  - Capture a question before finding an answer.
  - Save the useful parts of a failed experiment.
- Share something you learned.

Use a numbered list when the order matters:

1. Find one problem worth solving.
2. Make the smallest useful version.
   1. Explain what it does.
   2. Ask someone to try it.
3. Improve it from what you observe.

Task lists show progress. These are static Markdown checkboxes, rather than a saved interactive checklist:

- [x] Write a first draft.
- [x] Add an example.
- [ ] Replace the sample with your own story.

## Code blocks

Code blocks support syntax highlighting, a filename label, and a copy button. Long lines scroll inside the block.

```ts file="src/lib/greeting.ts"
type Reader = {
  name: string;
  language: "en" | "zh";
};

export function greet(reader: Reader): string {
  return `Hello, ${reader.name}. Make something worth sharing.`;
}
```

Line highlights and inline word highlights can draw attention to a change:

```ts file="src/lib/publishing.ts"
// [!code word:published]
const published = true; // [!code highlight]
const title = "Make room for good work";

if (published) {
  console.log(title);
}
```

Diff annotations help explain a before-and-after example:

```ts file="src/lib/preferences.ts"
const preference = "light"; // [!code --]
const preference = "system"; // [!code ++]
```

Here is a shell example with an intentionally long line:


## Math

Use the same LaTeX delimiters as Obsidian: `$...$` for an inline formula, and `$$...$$` on separate lines for a display formula. Articles, MDX pages, and video transcripts share this support. MathJax renders the formulas during the build, with no browser script or external font request.

Inline formulas fit into a sentence: $E = mc^2$, $e^{i\pi} + 1 = 0$, and $\alpha \in \mathbb{R}$. Literal inequality signs work too: $x > 0$.

```md
Inline: $E = mc^2$.

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

The quadratic formula uses a fraction, a square root, and a plus-or-minus sign:

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

Use `aligned` to keep related equations together:

$$
\begin{aligned}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} \\
\int_0^1 x^2\,dx &= \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3}
\end{aligned}
$$

Matrices use `&` between columns and `\\` between rows:

$$
A = \begin{pmatrix} a & b \\ c & d \end{pmatrix},
\qquad \det(A) = ad - bc
$$

Piecewise definitions use the `cases` environment:

$$
|x| = \begin{cases} x, & x \geq 0 \\ -x, & x < 0 \end{cases}
$$

Long inline formulas also scroll inside their own frame on a phone: $\mathcal{L}(\theta) = -\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log p_{\theta}(x_i) + (1-y_i)\log\left(1-p_{\theta}(x_i)\right)\right] + \lambda\sum_{j=1}^{d}\theta_j^2$.

Long display formulas have the same behavior. Focus a formula and use the arrow keys to scroll:

$$
\mathcal{L}(\theta) = -\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log p_{\theta}(x_i) + (1-y_i)\log\left(1-p_{\theta}(x_i)\right)\right] + \lambda\sum_{j=1}^{d}\theta_j^2
$$

A display inequality can use the greater-than sign directly:

$$
x > 0
$$

Code examples keep their literal dollar signs. For a price in normal text, escape the symbol as `\$20` to display \$20. These examples use standard LaTeX commands; Obsidian plugins and custom macros are not imported automatically.
